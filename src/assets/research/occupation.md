# 職種一覧を列挙せよ

あなたはリサーチ部門に所属する職業分類の専門家として、
以下に列挙する 4 つのタスクを実行せよ。

## 1. 登録済みの職種の抽出

以下のコマンドを使用して、既に TaskWarrior に登録済みの職種を抽出せよ。
`tail` コマンドを使用して、ヘッダー行を除外して抽出する。

```sh
task rc.verbose=n rc.report.mini.columns=description \
  project:am:research status:pending +occupation mini \
  | tail -n +4
```

抽出した職種のリストは後続タスクで使用するため、一時的に記憶せよ。
0 件の場合もあり得る。

## 2. 一意な職種の列挙

日本の多くの業種で共通に存在する **職種** を、可能な限り多く列挙せよ。
IT 系に傾倒せず、製造業やサービス業など、幅広い分野の職種を列挙せよ。

列挙した中から、1 で抽出した職種の重複や表記揺れを除外せよ。
例えば、1 で抽出した職種に「ソフトウェアエンジニア」がある場合、
「SE」などの表記揺れも除外せよ。一方で、部分的に重複するも、
分野が異なる職種は、両方とも残せ。
例えば、「ソフトウェアエンジニア」と「機械エンジニア」は、両方とも残す。
他にも「営業」と「マーケティング」など、役割が異なる職種は両方とも残す。

## 3. 一意な職種の TaskWarrior への登録

そうして一意な職種を抽出できたら、以下の形式で
1 職種 1 タスクとして以下の形式で TaskWarrior へ登録せよ。

- プロジェクト: `am:research`
- タグ:
  - `occupation`
- タスクの内容: 職種名

例:

```sh
task add project:am:research tag:occupation ソフトウェアエンジニア
task add project:am:research tag:occupation 工場作業員
```

## 4. 調査方法と調査結果のまとめと記録

あなたが 2 のタスク(一意な職種の列挙)において、どのように調べて、
何を見つけたのか、簡潔に報告せよ。例えば、どのような Web を参照したか、
どのようなキーワードで検索したかなどを報告せよ。
