# トレンド検索のためのジャンルを列挙せよ

あなたは優秀なマーケット リサーチャーとして、以下に列挙するタスクを列挙せよ。

## 1. 登録済みのジャンルの抽出

以下のコマンドを使用して、既に TaskWarrior に登録済みのジャンルを抽出せよ。

```sh
task rc.verbose=n rc.report.mini.columns=description \
  project:am:research status:pending +trends_genre mini \
  | tail -n +4
```

抽出したジャンルのリストは後続タスクで使用するため、一時的に記憶せよ。
0 件の場合もあり得る。

## 2. 一意なジャンルの列挙

日本の多様なトレンド検索で共通に存在する **ジャンル** を、可能な限り多く
列挙せよ。例えば、健康、ファッション、テクノロジー、エンターテインメント、
スポーツ、ビジネスなど、幅広い分野のジャンルを列挙せよ。

列挙した中から、1 で抽出したジャンルの重複や表記揺れを除外せよ。
例えば 1 で抽出したジャンルに「テクノロジー」がある場合、
「テック」などの表記揺れも除外せよ。一方で、部分的に重複するも、
分野が異なるジャンルは、両方とも残せ。例えば、「スポーツ」と
「エンターテインメント」など、部分的に重複するも焦点が異なるジャンルは、
両方とも残すこと。

## 3. 一意なジャンルの TaskWarrior への登録

そうして一意なジャンルを抽出できたら、以下の形式で
1 ジャンル 1 タスクとして以下の形式で TaskWarrior へ登録せよ。

- プロジェクト: `am:research`
- タグ:
  - `trends_genre`
- タスクの内容: ジャンル名

例:

```sh
task add project:am:research tag:trends_genre 健康
task add project:am:research tag:trends_genre ファッション
```

## 4. 調査方法と調査結果のまとめと記録

あなたが 2 のタスク(一意なジャンルの列挙)において、どのように調べて、
何を見つけたのか、簡潔に報告せよ。例えば、どのような Web を参照したのか、
どのようなキーワードで検索したのかなどを報告せよ。
