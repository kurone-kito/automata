# 業種・職種を結合せよ

あなたは優秀なマーケット リサーチャーとして、以下のタスクを逐次実行せよ。

## 1. 登録済みの業種と職種の抽出

以下のコマンドを使用して、既に TaskWarrior に登録済みの業種と職種を抽出せよ。

```sh
# 業種の抽出
task rc.verbose=n rc.report.mini.columns=description \
  project:am:research status:pending +industry mini \
  | tail -n +4

# 職種の抽出
task rc.verbose=n rc.report.mini.columns=description \
  project:am:research status:pending +occupation mini \
  | tail -n +4
```

抽出した業種と職種のリストは後続タスクで使用するため、一時的に記憶せよ。
いずれかが 0 件の場合、報告を出力の上、この時点でタスクを中止せよ。

## 2. 業種と職種を結合、簡易的なフィルタリング

予め列挙済みである業種と職種を総当たりで結合して、組み合わせごとに、
以下の簡易的な調査を行い、全てに合致するもののみを列挙せよ。

1. その業種に該当する職種が、そもそも存在するかどうか。
2. 該当の組み合わせに対して、Web で完結可能な何らかのサービスを提供できる、
   余地があるかどうか。
3. 該当の組み合わせに対する Web サービス提供において、
   要求資格や最低資本金など、何らかの障壁がないか、障壁が極端に低いこと。

調査においては、以下の点に注意する。

- 調査は短絡 AND で行う。1 の条件を満たさない場合、2, 3 の条件は調査しない。
- 調査は速度を優先し、あくまで簡易的なものとする。
- 判断が微妙なものは、低優先度扱いで残すこと。例えば Web 完結サービス提供に、
  若干の参入障壁があるが、工夫次第で参入の余地がある場合など。
- 件数が多くなることが予見できるため、ある程度蓄積できた時点で、
  逐次後続の TaskWarrior への登録を行うこと。

## 3. 結合した業種と職種の TaskWarrior への登録

そうして結合した業種と職種との組み合わせをフィルタリングできたら、
以下の形式で 1 結合 1 タスクとして以下の形式で TaskWarrior へ登録せよ。

ただし、既存と重複する組み合わせに関しては、重複分を除外して登録せよ。

- プロジェクト: `am:research`
- タグ:
  - `industry_occupation`
- タスクの内容: `<業種> - <職種>`

例:

```sh
task add project:am:research +industry_occupation "情報通信業 - ソフトウェアエンジニア"
task add project:am:research +industry_occupation "製造業 - 機械オペレーター"

# 2 における判断が微妙な組み合わせは優先度を下げて登録する
task add project:am:research priority:L +industry_occupation "教育 - 教師"
```

## 4. 調査方法と調査結果のまとめと記録

あなたが 2 のタスク(業種と職種の結合、簡易的なフィルタリング)において、
行ったことを簡潔に報告せよ。例えば、どのような Web を参照したのか、
どういう理由で特定の組み合わせを除外したのかなどを報告せよ。
